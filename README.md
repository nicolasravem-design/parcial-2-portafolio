# Portafolio profesional — Nicolás

Sitio web frontend responsive construido con **Bootstrap 5**, como entrega del Parcial 2.

## Secciones
1. **Sobre mí** — información personal
2. **Estudios realizados** — línea de tiempo de formación
3. **Proyectos y experiencia**
4. **Lenguajes y tecnologías**
5. **Áreas de interés profesional**
6. **Contacto**

## Tecnologías
- HTML5, CSS3 y JavaScript
- [Bootstrap 5.3](https://getbootstrap.com/) (grid, navbar colapsable, cards, progress, utilidades responsive)
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- Google Fonts (Inter, JetBrains Mono)

## Responsive
El diseño se adapta a pantallas pequeñas (móvil), medianas (tablet) y grandes (escritorio) usando el sistema de grillas de Bootstrap (`col-12`, `col-md-6`, `col-lg-4`, etc.) y el navbar colapsable. Incluye modo claro/oscuro.
